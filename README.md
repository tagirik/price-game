# Собери тариф для AI-продукта

`Собери тариф для AI-продукта` — автономный демонстрационный прототип линейного квеста для показа рабочей команде конференции.

## Как открыть

Откройте `index.html` в современном браузере. Сервер, интернет и установка зависимостей не нужны.

## Публикация на GitHub Pages

Папка подготовлена как корень отдельного репозитория GitHub. Важно, чтобы `index.html`, `app.js`, `styles.css` и папка `.github` находились на верхнем уровне репозитория.

1. Создайте на GitHub новый репозиторий.
2. Загрузите в него всё содержимое этой папки и отправьте изменения в ветку `main`.
3. Откройте `Settings → Pages`.
4. В разделе `Build and deployment` выберите источником `GitHub Actions`.
5. Дождитесь завершения workflow `Deploy to GitHub Pages` во вкладке `Actions`.

После успешного запуска адрес сайта появится в результате deployment и в `Settings → Pages`. Относительные пути позволяют публиковать прототип как на пользовательском домене `username.github.io`, так и внутри репозитория `username.github.io/repository-name/`.

Workflow можно запустить повторно вручную через `Actions → Deploy to GitHub Pages → Run workflow`.

## Что показывает прототип

- первый экран о том, почему развитие AI обостряет вопрос монетизации;
- отдельный вводный экран с ролью участника, шагами и ожидаемым результатом;
- отдельный этап выбора одного из трёх AI-продуктов;
- полные сценарии для анализа договоров, помощника маркетолога и агента поддержки;
- короткое объяснение задачи участника на каждом этапе;
- причинную цепочку `клиент → ценность → оплата → поведение → защита экономики → реакция рынка`;
- последствия, зависящие от решений участника;
- одну корректировку после обратной связи;
- персональную карту тарифной гипотезы с выводами о клиентской ценности, свободе использования и контроле экономики.

Полная таблица развилок для трёх предложенных продуктов находится в [`BRANCH_MATRIX.md`](BRANCH_MATRIX.md). Сценарии помощника маркетолога и агента поддержки реализованы как содержательные гипотезы и требуют проверки с экспертами.

## Границы прототипа

- Это материал для обсуждения механики, а не финальный дизайн активности.
- Все три продукта можно пройти полностью. Контент пока не является согласованной рекомендацией по монетизации.
- Числовая экономика и реальные тарифы продуктов Контура не используются.
- Персональные данные и email не собираются.
- В папку `ai-tariff-app` и сборки «Босса себестоимости» изменения не вносились.
